VividFusion là một trình phát video mạnh mẽ, hiện đại cho Android. Phát các file media của bạn và những link bạn cung cấp — URL trực tiếp, stream HLS/DASH, magnet link và file .torrent — với trình phát dựa trên Media3/ExoPlayer.

VividFusion không lưu trữ, lập chỉ mục hay cung cấp bất kỳ nội dung nào. Bạn tự mang link và tài khoản của mình; ứng dụng chỉ phát chúng.

TRÌNH PHÁT

• Media3/ExoPlayer với FFmpeg decoder cho nhiều loại codec
• HLS, DASH, SmoothStreaming và link HTTP(S) trực tiếp
• Picture-in-Picture và phát nền với điều khiển media
• Chọn track âm thanh / video / phụ đề
• Điều chỉnh kiểu dáng và độ trễ phụ đề
• Hỗ trợ Android TV & Leanback

HỖ TRỢ DEBRID

Kết nối tài khoản Real-Debrid, AllDebrid hoặc Premiumize của riêng bạn để mở khóa những link bạn đã có thành stream trực tiếp tốc độ cao — hoàn toàn do bạn kiểm soát. Tài khoản và link do bạn cung cấp.

PHÁT TORRENT

Mở magnet link hoặc file .torrent bạn cung cấp và phát qua engine torrent tích hợp, không cần tải toàn bộ file trước.

PHỤ ĐỀ

Tìm và tải phụ đề từ OpenSubtitles bằng nhiều ngôn ngữ, hoặc tải file SRT/VTT/ASS/TTML của riêng bạn.

FILE CỤC BỘ

Duyệt và phát các file video đã có trên thiết bị.

QUYỀN RIÊNG TƯ

VividFusion không thu thập nội dung bạn phát. Xem chính sách quyền riêng tư để biết chi tiết về dữ liệu chẩn đoán và quảng cáo.

Mang link của bạn và bắt đầu phát trong vài giây.
